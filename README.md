A simple python flask app that helps manage student marks and  calculate gpa of each student and enables download of the results

#Live demo
http://localhost:5000

#Features
-One login page for different levels(admin,lecturer,student)
-Add students
-Add and update grades
-Calculate average and grade,GPA
-view and download GPA

#Tech
Python flask,HTML/CSS

#How to run
1.pip install -r requirements.txt
2.python3 StudentSystem.py
3.open https://127.0.0.1:5000
